# Sprout Guardians 工程审计与改进记录（2026-11-23）

## 当前定位

默认运行入口是 Godot 4.7.1 的 90 秒植物主题 Survivors Roguelite，可在 Windows 和 Web 导出。现有内容包括主植物、两只浮游宠物、自动弹道、经验三选一、30/60 秒精英与最终 Boss；历史塔防/Greed 脚本仍在仓库中，属于兼容或参考实现。

以上修改增加了移动松键、鼠标移动保留、无效升级选择、空间查询、Boss 结算和连续两次存档损坏的回归测试。

## 仍需处理的重点

### P0 — 完整游玩体验

1. **多构筑分支**：目前升级复用既有祝福系统，大部分效果偏数值型。应新增主武器、浮游宠物、被动遗物分类，并至少实现六个可见的规则变异。
2. **敌人行为**：现有多数敌人仍基于同一个追击逻辑。优先增加远程、预警冲锋、分裂和召唤，并为最终 Boss 加入多阶段机制。
3. **局内信息**：增加暂停菜单、升级卡稀有度与攻击变化预览、本局构筑、伤害构成和结算明细。

### P1 — 运行性能与工程质量

1. **弹幕与特效池化**：Survivors 的 projectile 和经验掉落仍频繁创建/释放 Node。现有 `ProjectilePool` 服务面向旧塔防实体，不能直接等同于 Survivors 池。
2. **空间查询扩展**：当前空间索引用于敌人分离；主植物/宠物索敌、范围弹丸以及鼠标命中仍使用全体分组扫描。扩展前先用固定种子基准测试验证收益。
3. **HUD 更新**：部分 HUD 字符串每帧重建；应基于脏标记刷新，避免重复文本布局。
4. **存档原子提交**：此次解决的是「损坏主存档覆盖备份」问题，不等同于掉电安全。建议进一步设计临时文件、原子替换、校验和与保留多代备份。
5. **测试矩阵**：固定 20–50 个种子的弱/随机/强构筑仿真，以及 Web 浏览器实际启动和长时间泄漏测试。

### P2 — 内容与适配

- 16:10/超宽/高 DPI 的 HUD 自适应与可访问性
- 手柄、移动触屏、可重映射按键
- 原创完整角色、地图、图鉴、掉落与音效资源
- 更大 TileMap 地图与镜头跟随

## 验证方式

在 Godot 4.7.1 导入项目后运行：

```bash
godot --headless --path . --editor --quit
godot --headless --audio-driver Dummy --path . --script res://tests/run_tests.gd
godot --headless --audio-driver Dummy --path . --script res://tests/run_greed_mode_tests.gd
godot --headless --audio-driver Dummy --path . --script res://tests/run_survivor_tests.gd
```

完整 CI 仍需由 GitHub Actions 对所有测试、Windows/Web/Linux 导出和 Linux smoke test 进行验证。仅做静态检查不能声称通过引擎级运行测试。
