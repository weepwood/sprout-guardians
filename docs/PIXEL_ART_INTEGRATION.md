# 概念图像素素材接入说明

## 目标

以本次生成的“混乱的植物战场”概念图作为视觉母版，将其中的色彩、轮廓和信息层级整理为可以在 Godot 中重复使用的像素素材，而不是把整张概念图作为静态背景。

## 已提炼的视觉语言

- 深绿草地和暗色边缘，用于维持大量敌人出现时的可读性；
- 亮绿色叶片作为主武器弹道；
- 粉色花瓣作为范围伤害和孢子爆发；
- 蓝白晶体作为经验露珠；
- 粉绿花冠作为主植物；
- 黄色花朵和蓝色嫩芽作为两个浮游宠物；
- 绿色、紫色、食人花、金色精英和紫色 Boss 五类敌人轮廓；
- 深色木质面板、金色边框和绿色角饰作为 HUD 与升级界面。

## 素材结构

- `actors_atlas.svg`：主植物、两个浮游宠物、三种普通敌人、精英和 Boss；
- `effects_atlas.svg`：经验露珠、叶片/花瓣/冰晶弹道、生命/击杀/等级图标；
- `grass_tile.svg`：可平铺草地；
- `ui_panel.svg`：可九宫格拉伸的像素面板；
- `palette.svg`：概念图提炼色板。

SVG 全部使用整数坐标与 `shape-rendering="crispEdges"`，Godot 全局纹理过滤继续使用 Nearest，避免缩放后变模糊。

## 运行时接入

`PixelArtAssets` 负责图集切片和缓存，`PixelSkinController` 监听场景中新生成的主植物、宠物、敌人、投射物和经验露珠，并自动附加对应像素 Sprite。这样不会把视觉代码继续塞进战斗对象，也便于以后替换成正式逐帧动画图集。

## 原创边界

该素材仅使用时间生存游戏的通用可读性原则和本项目概念图中的植物主题。没有复制其他游戏的角色、地图、图标、敌人、美术资源、UI 布局文件或动画。
