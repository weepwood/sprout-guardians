# 生存模式迭代路线

## V0.5 数值基础
独立普通、精英、Boss 配置，90 秒连续血量曲线，30/60 秒喘息，三档难度，固定种子生成序列。初始普通 HP 18，90 秒 72，普通 Boss 850。参数为待试玩校准的初稿，不代表胜率。

## 后续验收
1. 固定种子实际战斗仿真：弱/随机/强构筑、走位、首次升级、死亡时间、Boss 耗时。
2. 投射物和经验对象池：回收时清除目标、信号、年龄、组成员；暂停恢复不得激活闲置对象。
3. 空间查询：处理 100ms 桶更新导致的漏查；与全局扫描对照测试。
4. 反馈：命中、暴击、拾取的限频与无障碍设置。
5. 美术：先审查可再分发许可，统一尺寸、色板、Idle/Walk/Hit/Death 动画。
6. 构筑、生态协同、地图与 Boss、局外成长。

## 集中开发进度
已加入对象复用、战斗空间查询、HUD 降频、实际命中与拾取音频反馈及拾取池回归测试。仍需引擎验证、真实战斗仿真和素材许可审查，不得标记为已通过。
