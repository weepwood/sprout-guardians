# 植物幸存者模式方向

项目默认玩法将从“十轮贪婪房间”转向原创植物主题的时间生存 Roguelite。

## 核心循环

`持续移动 → 自动攻击 → 击败敌人 → 拾取生命露珠经验 → 升级三选一 → 植物/宠物形成联动 → 精英与 Boss 时间节点 → 存活到结算`

## 玩家职责

- 使用 WASD、方向键、鼠标点击移动和闪避控制主植物
- 通过走位控制敌群密度、经验拾取路线和安全距离
- 升级时选择主植物变异、浮游宠物或全局遗物
- 不需要手动瞄准或频繁点击攻击

## 系统职责

- 主植物和浮游宠物自动寻找目标并攻击
- 敌人从竞技场边缘持续生成，强度随时间提升
- 敌人掉落经验露珠，接近主植物后自动吸附
- 达到经验阈值暂停战斗并打开三选一奖励
- 精英、Boss 和特殊敌人按时间节点出现

## 第一阶段可玩切片

- 90 秒时间生存关卡
- WASD/方向键连续移动，保留鼠标移动与闪避
- 连续刷怪，不再等待一波完全清空
- 经验露珠掉落、磁吸、拾取和等级进度
- 每次升级打开现有的 seeded 三选一变异界面
- 敌人生命、速度、生成间隔随时间分段成长
- 30 秒和 60 秒生成精英，90 秒生成首领并进入结算
- HUD 显示时间、等级、经验、生命与击杀数

## 后续阶段

1. 将祝福拆为武器、宠物、被动遗物三类。
2. 实现重复武器升级与武器进化配方。
3. 增加范围拾取、幸运、成长、冷却、持续时间等属性。
4. 建立大地图、镜头跟随和地图物件。
5. 增加敌人原型、精英词缀和多阶段 Boss。
6. 加入永久金币升级、角色解锁与图鉴。

## 原创边界

- 不复制其他游戏的角色、敌人、地图、图标、音效、文案或数值表。
- 只使用时间生存、自动攻击和 Roguelite 构筑等通用玩法结构。
- 保持植物主角、浮游宠物、花园变异和像素植物生态的独立识别度。
