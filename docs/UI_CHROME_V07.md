# V0.7 UI 控件体系
- 语义图标使用 Lucide 0.456.0 官方 SVG（https://github.com/lucide-icons/lucide/tree/0.456.0/icons），原始24单位坐标与2单位描边不变，只调整输出尺寸为96和白色基准，运行时按按钮状态/主题着色。许可沿用 assets/ui/buff/LICENSE.txt（所有导出已包含）。角色、武器、地图及奖励美术保持原位图。
- 控件文字优先13、次级11、正文12、指标16、弹窗标题22逻辑像素；适配时测量实际字体和图标/边距预算，避免长文案抬高控件。保留原生按钮焦点、文本、键鼠与禁用状态。
- 设置面板密集行统一；暂停弹窗按真实构筑行数收缩高度；结算指标采用语义图标、标签与大数值。HUD小于560逻辑像素时采用紧凑布局，不修改世界相机或战斗机制。
- Acrylic使用单次背景mipmap采样、像素尺度抗锯齿、上亮下暗边缘及轻量内缘，保留浅色奖励14px圆角与实色降级。非系统原生DWM。
