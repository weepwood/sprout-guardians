# Sprout Guardians v0.2.0 — 花园新装扮

本版本重点完善植物幸存者模式的操控、性能与存档可靠性，同时提供 Windows、macOS 与 Web 的正式构建。

## 新功能
- macOS Universal 2 桌面包：同时支持 Apple Silicon 与 Intel Mac，提供 DMG 和 ZIP。
- Windows x86-64 免安装版，解压后直接运行。
- 全新暖色、圆角、玩具感的植物主题 UI：主菜单、战斗 HUD、升级选项和结算界面。
- 增加 `Esc` / `P` 暂停菜单，支持继续游戏和返回主菜单。
- 按钮加入更清晰的悬停、键盘焦点和操作反馈。

## 质量改进
- 修复松开移动键后主植物仍继续移动的问题，保留鼠标移动方式。
- 优化敌群近邻查询、减少不必要的逐帧重绘。
- 击败最终 Boss 后及时结算。
- 优化升级选项边界处理。
- 修复损坏主存档恢复时覆盖有效备份的问题。
- 完善自动测试、跨平台导出和 CI 发布权限。

## 下载与安装

| 平台 | 文件 | 使用方法 |
| --- | --- | --- |
| Windows x64 | `SproutGuardians-Windows-x86_64.zip` | 解压，双击 `SproutGuardians.exe` |
| macOS Intel / Apple Silicon | `SproutGuardians-macOS-Universal.dmg` | 打开 DMG，将应用拖入“应用程序” |
| macOS Intel / Apple Silicon | `SproutGuardians-macOS-Universal.zip` | 解压 `.app` 后放入“应用程序” |
| Web | `SproutGuardians-Web.zip` | 提供给静态 Web 服务器部署 |

**注意：** macOS 版目前使用临时签名，尚未 Apple Developer ID 公证；首次运行可能需要在“系统设置 → 隐私与安全性”中允许。Windows 版目前也尚无商业代码签名。

构建和自动化测试基于 Godot 4.7.1。若需查看完整设计与技术说明，请参阅 `docs/DESKTOP_PACKAGING_AND_UI.md`。
