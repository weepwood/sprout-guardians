# Sprout Guardians v0.3.0 — 花园焕新与稳定性更新

这是 v0.2.0 之后的首个素材驱动重构版本。主要目标是摆脱战斗单位的代码即时绘制、减少长时间战斗的资源累积，并让本地战绩真正可用。

## 游戏体验
- 全新的原创透明 PNG 花园玩具风素材：主植物、两名浮游伙伴、普通敌人、精英/Boss、种子弹丸、经验露珠及命中特效。
- `Sprite2D` / `AtlasTexture` 接入可编辑场景，生存模式不再用 `_draw()` 描绘实体本体；保留旧玩法兼容路径。
- 首页新增可打开的 **花园战绩（Garden Journal）**：记录累计挑战、胜负、最长生存、最高等级和最多击杀。
- 生存局结果自动写入原有存档系统，兼容 v0.2.0 旧存档。

## 质量与架构
- 修复长期战斗中伤害数字 Label 不回收的问题，采用有上限的对象池。
- 命中特效改为带容量限制的素材精灵池，减少每帧程序绘制。
- 新增 `SurvivorRunState` 单局状态机、运行阶段日志和 Godot 原生日志。
- 增加完整 90 秒游戏流程、Boss、升级、暂停、精灵池压力测试。
- 增加 Windows/macOS/Linux 原生应用进入生存场景的 smoke checks（无界面方式运行）。

## 下载
- Windows x64：`SproutGuardians-Windows-x86_64.zip`，解压后运行 EXE
- macOS Intel + Apple Silicon：`SproutGuardians-macOS-Universal.dmg` / `.zip`
- Web：`SproutGuardians-Web.zip`，用于静态网站部署

> **尚未彻底消除用户环境下的闪退风险。** 由于没有对应的原生系统崩溃报告，本次通过了自动化测试但不能保证所有 GPU/驱动/窗口相关错误已经解决。请参见 `docs/REFACTOR_AND_CRASH_DIAGNOSTICS.md` 收集本机日志。
>
> macOS 仍采用 ad-hoc 签名，未经过 Apple Developer ID 公证；首次打开可能需要手动允许。Windows EXE 亦未做商业代码签名。
