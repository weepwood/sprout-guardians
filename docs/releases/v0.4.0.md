# Sprout Guardians v0.4.0 — 花园幸存者模式

本次版本将生存模式调整为更纯粹的「移动 + 自动攻击 + 收集经验 + 三选一升级」循环，界面与素材保持原创植物花园主题。

## 玩法与操作
- WASD、方向键实时八方向移动，松开立即停止，对角线移动速度归一化。
- 主植物与浮游伙伴持续自动索敌和攻击；生存模式不再依赖鼠标点地移动、拖动角色或手动锁定敌人。
- 基础冲刺在生存模式下取消；原有 Greed 模式保留此前操作。
- 提高刷怪密度与经验掉落吸附范围；敌人在视野边缘更合理地进入，避免与角色直接贴脸生成。
- 精英怪 / Boss 到来时显示短暂的战斗警报，连续击杀出现限时连击提示。

## UI 与美术
- 使用原创全屏花园地面 SVG 背景，不再绘制厚重场地边框。
- 压缩顶部 HUD，底部只保留细经验条；构筑信息移至暂停面板，开局操作提示短时间后隐藏。
- 在有限 HUD 区域使用轻量的屏幕纹理毛玻璃着色器。
- 升级奖励改为并排三张横向卡，显示图标、稀有度、名称、说明与等级。
- 支持鼠标选择，或用左右键移动焦点、Enter/Space 确认、数字键 1/2/3 快速选择。

## 稳定性与工程
- 输入逻辑独立为 `SurvivorInputController`，旧玩法的鼠标事件不再影响生存角色。
- 增加按键松开即停、鼠标锁敌禁用、横向奖励卡、危险刷怪边距和短时警报等回归测试。
- 保留既有长局集成测试、存档兼容、Windows 原生运行测试与 macOS Universal 打包验证。

## 下载
- Windows x64：`SproutGuardians-Windows-x86_64.zip`（解压运行）
- macOS Intel / Apple Silicon：`SproutGuardians-macOS-Universal.dmg` 或 `.zip`
- Web：`SproutGuardians-Web.zip`（部署到静态 Web 服务器）

**安装限制：** macOS 版本仍使用 ad-hoc 签名，尚未 Apple Developer ID 公证；首次打开可能需要在系统安全设置中允许。Windows 版本仍未进行商业代码签名。

## 尚待实现
本版仍是固定视口竞技场，并非无限滚动世界；主角动画、更多武器进化与复杂 Boss AI、触控虚拟摇杆仍待后续迭代。已知的用户本机闪退问题仍需本机诊断日志来判断是否完全消除。
