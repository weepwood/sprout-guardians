# Sprout Guardians v0.5.0

> 发布门禁：仅在候选通过审查合并、main 同一 SHA 的构建、144组平衡仿真及质量专项全部成功后，由独立发布工作流发布。

## 主要变化
- 独立生存数值体系、三档难度、五个角色、四种地图，90秒生存与无尽模式。
- 地图专属首领、事件道具、六种常规武器及两种无尽武器、进化共鸣。
- 角色解锁、永久升级、每日挑战、地图胜利统计、成就及无尽纪录。
- 真实生成式 PNG 美术（芽芽与冰晶花各20帧、地图首领、敌人和道具）；奖励可读性、选角、图鉴、结算与HUD改善。
- 对象池、空间索引、存档替换与恢复；144组仿真、600秒辅助压力、120秒带渲染基准、截图与跨平台验收。

## 兼容和限制
- 旧存档保留已开放地图；新增地图胜利记录从新版开始累积。
- 无尽两种武器具备独立生成PNG图标。高清地表可选素材尚未随候选提交；原纹理回退可运行。向日葵、共生芽、荆棘卫士完整独立动作尚未完成。
- macOS 为 ad-hoc 签名 Universal ZIP/DMG，并非 Apple notarized。Windows/Linux 为 ZIP 可执行包，Web 为静态站点包。
- 性能基准不等同于物理低端 GPU 实测；每日挑战为本地记录，不提供服务端防作弊排行榜。

## 验收与产物
发布工作流校验同一 main SHA 三套最新成功工作流、ZIP 完整性并生成 SHA256SUMS.txt。实际运行证据见对应 GitHub Actions。
