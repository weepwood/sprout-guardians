# Sprout Guardians v0.6.0 发布候选
- 全彩高清地图、五角色各20帧、独立森林菜单背景、高清敌人/Boss静态素材、八武器图标与24种独立特效。
- 四地图各六种独立装饰PNG；独立视觉随机数，不影响玩法。
- 根据玩家反馈新增明确的简单档、减轻普通后期敌群压力、提高经验成长与拾取效率；专家、碰撞、武器冷却及存档档位编号保留。Buff标题、描述、稀有度及提示采用高对比度文本。
- 必须复核实际46张场景/特效截图、四地图装饰、144组仿真、跨平台构建及存档、压力与渲染质量。敌人独立动画尚未齐备，仍为草稿。
- 发布工作流只接受已审查的当前main SHA，四套push CI全部成功；从同一构建下载5个包，验证ZIP与SHA256。macOS 默认要求 Developer ID 与 Apple 公证；个人测试可显式允许临时签名并保留状态文件；Windows/Linux为可执行ZIP。

- 简单/普通武器构筑辅助、等级输出与间隔收益；奖励卡显示升级前后数值与进化条件，所有地图远程敌群限额；专家保留原规则。修正双语截图测试。

- macOS 拖拽式 DMG、最终镜像复制后真实启动检查；统一高清芽芽图标。未配置 Apple 签名时仍可能被 Gatekeeper 拒绝。
