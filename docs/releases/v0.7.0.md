# Sprout Guardians v0.7.0

- 窗口采用保持比例的连续缩放与扩展视口；菜单背景填充实际窗口，战斗 HUD 锚定四周。
- 显示模式、窗口分辨率、界面缩放及音乐/音效音量保存至原有设置文件，旧 fullscreen 设置兼容迁移。
- 经典地图保持原有可战斗区域及数值，扩展空间呈现环境背景；探索地图依据实际相机可视区计算生成边缘并限制在世界内。
- 森林奇幻主题：精简战斗状态栏、生命与经验进度、武器图标；低频语言和倍速移入暂停界面。
- 更新角色卡与角色预览、地图信息、显示与音频设置、横向奖励卡及结算统计。
- 复用 V0.6 高清资源；不更改战斗伤害、速度、经验曲线、存档记录或难度编号。
- 适配测试覆盖 4:3 / 16:9 / 16:10 / 21:9，UI 缩放会在极窄视口自动限制以确保弹窗可用。
- 正式发布须通过同 SHA 四套 CI、真实截图审查与跨平台制品校验。macOS 公证状态以正式包实际结果为准；不得默认放宽签名门禁。
